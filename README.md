# Proyecto Zoolomascotas MX

## Descripción
Sistema de informacion veterinaria ZoolomascotasMx.

## Metodología
A partir del análisis de la problemática identificada en la clínica veterinaria Zoolomascotas MX, se evidenció que procesos como la gestión de citas, los historiales clínicos, la hospitalización e insumos de medicamentos se realizan de forma manual y poco organizada. Esto genera demoras, pérdidas de información y dificultades para acceder a datos importantes durante la atención y el seguimiento de las mascotas, afectando la eficiencia del personal y la calidad del servicio ofrecido a los propietarios.

Para mejorar el rendimiento en la prestación de sus servicios, se hace necesario implementar un sistema de información que apoye y centralice estos procesos. Con ello, la veterinaria contará con información oportuna y veraz, lo que permitirá agilizar las actividades internas, reducir errores y ofrecer una atención más organizada, eficiente y confiable tanto para los empleados como para los clientes.
